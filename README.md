# HOS Planner

A US hours-of-service trip planner for property-carrying drivers. It runs in the browser as a single HTML file and works offline.

## Features
- Day grids that start today, with Off, Sleeper, Driving and On duty rows
- Break, 11-hour drive, 14-hour window and 70-hour cycle clocks
- Split sleeper toggle
- Automatic trip planner by driving hours or desired miles, with cycle hours left
- Per-day violation list and collapsible plan days
- Light and dark themes, saved automatically on your device

## Use
Open the published page, or open `index.html` in any modern browser.

## Disclaimer
This is a planning tool only. It is not a certified ELD and is not legal or compliance advice. Always follow current FMCSA regulations (49 CFR Part 395) and your carrier's policies.
